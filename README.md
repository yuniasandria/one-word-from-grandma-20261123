# One Word From Grandma

Entry for the make.fun bounty "One Word From Grandma"
(`u-0xkianno-one-word-from-grandma-f04bed16`).

The program writes exactly one word to `/output/entry.txt`: the single word
grandma would text about AI.

## The word

**doohickey**

Grandma's word for any gadget she can't name — warm, a little baffled, and
funny in one word, with no caption needed. It is what she would actually
text her grandchild about the AI thing: not a technical term, not a joke
explained, just the doohickey.

## Run

```sh
python3 main.py
```

Writes `doohickey` (9 characters, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
